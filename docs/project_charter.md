# Project Charter

## Project
**Walmart Demand Planning Analytics**

## Business problem
Retail planners need to balance availability and inventory exposure across thousands of item-store combinations whose demand patterns differ substantially. A single forecasting method and a single replenishment rule are unlikely to work across stable, intermittent, volatile, and long-tail demand.

## Project goal
Build an end-to-end planning workflow that combines demand segmentation, forecast model selection, value prioritization, scenario-based inventory coverage, and planner actions.

## Primary audiences
- Demand Planner
- Merchandise Planner
- Inventory / Replenishment Planner
- Business Intelligence Analyst
- Retail Data Analyst

## Success criteria
- Transparent 28-day time-based forecast validation
- Demand-pattern-aware model routing
- ML improvement demonstrated on high-value priority series
- Planner-facing outputs rather than model metrics alone
- Clear distinction between observed data and modeled scenarios
- Reproducible Python / SQL workflow suitable for GitHub review
